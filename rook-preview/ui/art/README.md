# Painted UI art (Lumenhold)

Hand-painted on the desk Mac (FLUX.2 Klein, local, free) and cut out with RMBG-2.0. Transparent WebP.
Concept mockups for the intended look: `art/review/ui-concept-hud-u1.png`, `art/review/ui-concept-menu-u1.png`.

| file | what it is | use it for | 9-slice hint (border-image) |
|---|---|---|---|
| attack.webp | brass cog medallion, gauntlet fist on leather, teal crystals | the ATTACK button | (round: background-image) |
| socket.webp | brass rune ring, empty dark glass centre | skill / dodge / charge sockets, gear slots | (round) |
| orb.webp | glass orb in a brass cage with a crown | the Musou / ultimate gauge (fill inside the glass) | (shaped) |
| portrait.webp | rounded-square brass cameo frame, dark window | hero and officer portraits | ~16% each side |
| plaque.webp | wide brass plaque, filigree border, teal crystal ends | buttons (.tb-btn) | ~18% left/right, ~28% top/bottom |
| panel.webp | oxblood leather, stitched edges, brass corner caps | panels (.tb-panel), menus, overlays | ~14% each side |
| gauge.webp | brass tube with a long glass window, heart cap left | the Heart HP bar and other bars | ~10% left/right, ~35% top/bottom |
| banner.webp | parchment scroll with wooden rollers | titles, wave counter, officer banner | ~13% left/right |
| coin.webp | brass badge with a glowing amber spark star | Sparks counter, currency chips | (round) |
| seal.webp | red wax-seal medallion with a crest | badges, claim stamps, DEFEATED stamp | (round) |
| icon-dodge.webp | winged brass boot | the DODGE emblem | (icon) |
| icon-charge.webp | amber spiral rune in a brass pendant | the CHARGE emblem | (icon) |
| icon-horn.webp | brass war horn with a teal crystal | Call wave | (icon) |

The 9-slice percentages are estimates from the paintings; measure against the image before relying on them.
