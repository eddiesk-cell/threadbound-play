# UI art (2026-10-22)

Made for the menu redesign Eddie asked for: *"the game landing page should have an epic image of heroes standing together
… Loom should stand out with rate up heroes showing … we must generate more UI objects"*. He approved Higgsfield
("we have credit left but go easy on it"). Engine: Higgsfield, Nano Banana Pro, 2k, 2 credits an image; 8 images, 16 credits.

- `keyart.webp`: all eight heroes on a rise above Lumenhold at dusk. Reference input: our own in-game renders of the eight
  heroes (`?puppet=roster`), never Eddie's reference images. One edit pass gave Rook his single gauntlet back.
- `logo.webp`: the title logo, **Legend Defenders** (Eddie's release name, 2026-10-22), keyed from black to alpha. Its dark
  outline keys away, so give it a soft dark drop shadow on the key art. (The first logo read Threadbound; see git history.)
- `banner-nell.webp`, `banner-mirela.webp`: rate-up splashes for the two SSR heroes (the key art as reference); the
  figure is on the right, the left 45% is clear for text.
- `icons/*.webp`: twelve painted icons cut from one 4x3 sheet (white flood-filled to alpha): fight, heroes, gear, loom,
  missions, chest, gift, settings, gem, coin, checklist, calendar.
- `faces/*.webp`: a head-and-shoulders portrait of each hero, cropped from the key art.
